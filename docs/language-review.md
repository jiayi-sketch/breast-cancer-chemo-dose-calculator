# 1.0.2 语言核对记录

支持简体中文（默认）、繁體中文及 English。所有平台使用同一份 `data/i18n.json`、共享界面、结构化目录和算术核心。

翻译覆盖两页静态标签、方案/药物名称、给药频次与疗程、18张指南摘要、录入核对提示、计算错误及复制核对单。繁体转换由 Apple Foundation 的 Simplified-Traditional 转换生成后随源码固定分发；无需联网或翻译服务。英文药物名称采用通用名，例如[美国国家癌症研究所的 nab-paclitaxel 词条](https://www.cancer.gov/publications/dictionaries/cancer-drug/def/nab-paclitaxel)。翻译保留原指南推荐层级、数值、周期和页码；不更新临床推荐，不将出版时审批状态当作当前审批状态。

语言切换保留已输入的数值、姓名/代号、来源和备选频次；清空旧结果、复制内容和确认。用户手动填写的文字保持原样，不进行翻译。完整核对 JSON 保留原始目录措辞；屏幕说明及复制核对单使用当前语言。

原生外壳仅保存白名单中的 `zh-Hans`、`zh-Hant` 或 `en`：Mac 的 UserDefaults、Android 的 SharedPreferences、Windows 的本地语言配置文件。网页存储仍关闭/不使用，病例参数不随语言设置保存。页面间跳转携带语言，关闭再打开恢复语言。

语言回归测试包括所有内置内容英文覆盖、三语数值一致、各计算方式、备选频次、输入原文保留、异常提示、语言切换失效处理及延迟剪贴板回执。DOM 测试不能证明原生页面布局、医学翻译质量或临床适用性。安装包和原生检查结果随发布校验记录列明。

英文及繁体内容未经独立临床专业复核；使用时仍须结合原指南。原始指南 PDF、真实患者资料及签名私钥不分发。
