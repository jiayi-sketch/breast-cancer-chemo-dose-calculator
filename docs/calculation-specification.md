# 算术接口与迁移差异

本文描述原程序的算术行为，不是已验证的临床给药指南。所有系数由使用者手动录入。

## 输入

沿用旧实现范围：身高 80–250 cm、体重 20–350 kg、肾功能参数 0–200 mL/min，包含边界。这些范围不代表临床适用标准。

拒绝空值、非数字、字符串数值、NaN、无穷值、非正系数、反向区间和非有限结果。界面只将非空数字框转换为数值。固定剂量无需身高/体重，按体重无需身高。

| 类型 | 运算 |
| --- | --- |
| bsa | BSA = √(身高 cm × 体重 kg / 3600)；剂量 mg = 系数 mg/m² × BSA |
| bsa_range | 分别计算下限与上限，相同边界合并为单值 |
| weight | 剂量 mg = 系数 mg/kg × 体重 kg |
| weight_seq | 分别计算首剂与后续剂量 |
| fixed | 使用固定剂量 mg |
| fixed_seq | 分别保留首剂和后续固定剂量 |
| fixed_alt | 两个固定剂量分别绑定频次，明确选择其中一个 |
| auc | 剂量 mg = AUC 系数 × (已核对肾功能参数 mL/min + 25) |

AUC 要求记录参数来源/方法、单位与适用性确认。不把 mL/min/1.73m² 的标准化 eGFR 自动当作相同数值，不估算肾功能或设置上限。旧程序混合标注 GFR/CrCl；新接口不替使用者判断它们能否互换。

## 输出与阻断

核心使用 JavaScript Number 保留未舍入值，界面显示 2 位小数。没有按药品规格取整、临床最大剂量或自动减量。

规则需含 ID、版本、依据标题/版本/位置、核对人、日期和本次确认。界面生成的 approved 仅表示手动确认，不是认证或临床批准。缺项或非法时返回 blocked、invalid、needs-input 或 needs-selection，无剂量输出。

任何输入变化清除旧结果与确认，肾功能值/方法变化同时清除肾功能确认。复制是用户主动操作，摘要写入系统剪贴板后由系统管理，不受应用清空操作控制。

## 验证

40 个合成向量对比隔离的旧算术参考与新核心，容差 0.005 mg 对应旧界面两位小数格式。另有 11 组核心测试覆盖边界、单位、溢出、依据、备选等。独立简单算例为身高 180 cm、体重 80 kg → BSA 2 m²，虚构系数 7.5 → 15 mg。

测试证明所覆盖的算术及输入控制行为，不验证药物方案或患者结局。
