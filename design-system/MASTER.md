# Language setting design

Preserve the existing clinical workspace, blue accents, neutral panels and system typography. Place the labelled language selector in the header on both pages. Keep 简体中文, 繁體中文 and English readable in their own scripts.

Selectors have a minimum 44px target and visible keyboard focus. Headers wrap on narrow screens. Regimen rows grow with content; English names wrap without clipping. Preserve units and source page numbers. Language changes retain inputs and clear prior results and confirmations. Announce the change through the existing status region. Avoid storing patient parameters.
